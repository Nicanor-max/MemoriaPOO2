## 🕹️ MemoriaPOO2

Simulador de procesos y gestión de memoria desarrollado en TypeScript, aplicando los conceptos de Programación Orientada a Objetos. Permite asignar memoria con las políticas First Fit, Best Fit y Worst Fit, ejecutar procesos y consultar métricas del sistema.

## 🚀 Instalación

Para instalar correctamente el proyecto y ejecutar los tests, seguí los siguientes pasos.

### 1. Requisitos

Es necesario tener instalado:

- Node.js
- npm

Podés comprobar las versiones instaladas mediante:

```bash
node --version
npm --version
```

### 2. Instalar las dependencias

Desde la carpeta del proyecto, ejecutá:

```bash
npm install
```

## 🧪 Tests

Para correr los tests, utilizá alguno de estos comandos:

```bash
npx vitest run
npm test
```

Para ejecutar los tests automáticamente cada vez que modificás el código:

```bash
npm run test:watch
```

## 📊 Coverage

Para ver el porcentaje de cobertura, utilizá alguno de estos comandos:

```bash
npm run test:cov
npx vitest run --coverage
```

## 🔎 Verificación de tipos

Para comprobar los tipos de TypeScript, ejecutá:

```bash
npm run typecheck
```
